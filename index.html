Installation

  1. Download InfiniteGlade-v1.0.0.zip.
  2. Extract all contents into your Tiny Glade root folder: 
    C:\Program Files (x86)\Steam\steamapps\common\Tiny Glade\
  3. Run install.bat (or copy GladeLoader.exe, glade_loader.dll, and the assets\ folder manually).
  4. Launch the game using GladeLoader.exe.
Steam Launch Options Tip: To launch through the standard Steam "Play" button, open Tiny Glade Properties in Steam, navigate to General > Launch Options, and enter: 
"C:\Program Files (x86)\Steam\steamapps\common\Tiny Glade\GladeLoader.exe" %command%

Save Game Safety

Tiny Glade's serialization logic stores all geometry coordinates into standard world save files, including structures placed outside the 40-meter radius.

Important: If you launch the game in vanilla mode (without the loader), vanilla boundary routines will reject edit operations on out-of-bounds structures. To edit or expand them, always run the game via GladeLoader.exe.

Save directory location:

%USERPROFILE%\Saved Games\Tiny Glade\Steam\<YourSteamID>\saves\

Frequently Asked Questions

Windows SmartScreen flagged GladeLoader.exe. Is it safe?

Yes. GladeLoader is an open-source Win32 process injector written in Rust. Because it is not signed with an expensive commercial EV certificate and invokes CreateRemoteThread, generic heuristics flag it. Click More info > Run anyway. The full source code is available on GitHub for independent review.

What happens when Tiny Glade receives an update on Steam?

The current release relies on hardcoded RVAs for build v1.16.0-pre4. If a game patch updates executable offsets, the loader will safely fail to hook without corrupting game files. Open a ticket on GitHub Issues, and an offset update will be published. Dynamic signature scanning (AOB) is currently in development.

Does this affect game achievements?

No. Steam achievements and Steam overlay function normally when injected via GladeLoader.
